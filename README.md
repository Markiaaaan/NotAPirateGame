# Привид підземелля

Стелс-гра про прозорого привида в підземеллях старого міста. Вночі тут прокидаються мерці. У темряві привида не видно, а світло його виказує. Щоб вибратися нагору, привид заманює нежить шумом: розбиває глечики, заводить патефон, б'є в дзвін, штовхає лицарські обладунки.

Вороги:
- **Скелет** несе ліхтар, і в радіусі ~3 клітинок привида видно з усіх боків. Бачить далеко, але тільки освітленого привида. Через річку не ходить.
- **Злий дух** без світла, зате відчуває привида зблизька (~2 клітинки) навіть у темряві, навіть спиною. Літає над річкою.

Рівні: **Винні льохи**, **Катакомби**, **Підземна річка**, **Склеп**. Перед першим рівнем показується передісторія, після останнього - фінал (Enter - далі, Esc - пропустити). Між рівнями привид летить тунелем, поки вантажиться наступний рівень. На першому рівні внизу спливають підказки, як грати.

## Вихід і важіль

Вихід з рівня - двері. На кожному рівні вони спершу замкнені. Відмикає їх **важіль** (E, на мінікарті - жовта точка, що блимає). Але важіль гуркоче на все підземелля - вороги збігаються до нього. Можна потягнути й прослизнути до виходу, поки всі біжать туди. Відімкнені двері самі розчиняються, коли підлітаєш, і зачиняються, коли відлітаєш.

## Інтерфейс

- Ліворуч угорі - рівень і час. Праворуч (під мінікартою в 3D) - завдання: знайти важіль / вихід відчинено.
- Ліворуч унизу - твій привид (у 3D) і око: СХОВАНИЙ / ТЕБЕ ВИДНО / ПОГОНЯ. По краях екрана - блакитне світіння, коли тебе видно, червоне, коли женуться.
- Esc - пауза: продовжити, заново, гучність, чутливість миші, вихід у меню.
- Енергії немає: приманки безкоштовні, але мають перезарядку.

## Меню

- **Грати** - передісторія й перший рівень.
- **Скіни** - вибір вигляду привида: Класичний, Кучерявий, Рокер, Розвідник.
- **Налаштування** - гучність музики й звуків, чутливість миші, вигляд 3D / 2D, складність (Легко / Нормально / Важко), повний екран.

## Керування

WASD - летіти. Миша або стрілки ← → - поворот (у 3D). E - використати приманку чи важіль. R - почати рівень заново. Esc - пауза.
