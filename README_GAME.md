# Привид підземелля

Стелс-гра про прозорого привида в підземеллях старого міста. Вночі тут прокидаються мерці. У темряві привида не видно, а світло його виказує. Щоб вибратися нагору, привид заманює нежить шумом: розбиває глечики, заводить патефон, б'є в дзвін, штовхає лицарські обладунки.

Вороги:
- **Скелет** несе ліхтар, і в радіусі ~3 клітинок привида видно з усіх боків. Бачить далеко, але тільки освітленого привида. Через річку не ходить.
- **Злий дух** без світла, зате відчуває привида зблизька (~2 клітинки) навіть у темряві, навіть спиною. Літає над річкою.

Рівні: **Винні льохи**, **Катакомби**, **Підземна річка**, **Склеп**. Перед першим рівнем показується передісторія, після останнього - фінал (Enter - далі, Esc - пропустити). Між рівнями привид летить тунелем, поки вантажиться наступний рівень. На першому рівні внизу спливають підказки, як грати.

## Вихід і важіль

Вихід з рівня - двері. На кожному рівні вони спершу замкнені. Відмикає їх **важіль** (E, на мінікарті - жовта точка, що блимає). Але важіль гуркоче на все підземелля - вороги збігаються до нього. Можна потягнути й прослизнути до виходу, поки всі біжать туди. Відімкнені двері самі розчиняються, коли підлітаєш, і зачиняються, коли відлітаєш.

## Інтерфейс

- Ліворуч угорі - рівень і час. Праворуч (під мінікартою в 3D) - завдання: знайти важіль / вихід відчинено.
- Ліворуч унизу - твій привид (у 3D) і око: СХОВАНИЙ / ТЕБЕ ВИДНО / ПОГОНЯ. По краях екрана - блакитне світіння, коли тебе видно, червоне, коли женуться.
- Esc - пауза: продовжити, заново, гучність, чутливість миші, вихід у меню.
- Енергії немає: приманки безкоштовні, але мають перезарядку.

## Меню

- **Грати** - передісторія й перший рівень.
- **Скіни** - вибір вигляду привида: Класичний, Кучерявий, Рокер, Розвідник.
- **Налаштування** - гучність музики й звуків, чутливість миші, вигляд 3D / 2D, складність (Легко / Нормально / Важко), повний екран.

Все зберігається між запусками (PlayerPrefs). Мишею теж можна клацати, колесо змінює значення.

## Як зібрати гру

1. Відкрий проєкт у Unity і дочекайся, поки скомпілюються скрипти.
2. Меню **Tools > Ghost > Зібрати всю гру**.
3. Відкриється сцена `MainMenu`. Тисни **Play**.

Кнопка створює префаби в `Assets/Prefabs` (лише ті, яких ще немає, або всі, якщо змінилася версія), сцени `MainMenu`, `Intro` і `Level_01..04` в `Assets/Scenes` і записує їх у Build Profiles. Старий префаб `Guard` більше не потрібен, його можна видалити.

**Tools > Ghost > Перезібрати префаби й гру** створює префаби заново (ручні зміни в них зникнуть).

## Керування

WASD - летіти. Миша або стрілки ← → - поворот (у 3D). E - використати приманку чи важіль. R - почати рівень заново. Esc - пауза.

## Як змінити рівень

Рівні лежать у `Assets/Levels/level_01.txt` і т.д. Відредагуй текст і натисни «Зібрати всю гру». Новий файл `level_05.txt` автоматично стане п'ятим рівнем.

```
name: Назва рівня
hint: Підказка, що з'являється на старті
skeleton: 1 2 3 4   <- скелет ходить по точках 1, 2, 3, 4 (і по колу)
skeleton: 5         <- скелет, що стоїть на місці й роззирається
spirit: 6 7 a       <- злий дух (точки можуть бути й на воді)
map:
########
#P..1..E
########
```

| Символ | Що це |
|---|---|
| `#` | цегляна стіна (деякі автоматично з факелом, ґратами, павутиною, мапою) |
| `.` | кам'яна підлога |
| `,` | бруківка |
| `~` | підземна річка: привид і духи пролітають, скелети обходять |
| `P` | старт привида (рівно один) |
| `E` | вихід (ставиться на місце стіни). Якщо на карті є `X`, він замкнений до важеля |
| `1`..`9`, `a`..`l` | точки маршрутів; ворог з'являється на першій точці свого маршруту |
| `S` | винні полиці або бочки |
| `s` | ніші з черепами або архів |
| `O` | кам'яна колона (за нею не видно) |
| `C` | саркофаг |
| `p` | купа кісток |
| `R` | бочка |
| `B` | ящики |
| `K` | вагонетка |
| `J` | свічки на черепі (світяться) |
| `L` | смолоскип (освітлює коло, у якому привида видно) |
| `V` | глечик (разова приманка) |
| `T` | патефон (грає 5 секунд) |
| `H` | дзвін (найгучніший) |
| `M` | лицарські обладунки; `m` поруч показує, куди їх штовхнути |
| `X` | важіль: відмикає вихід і гучно приманює ворогів (один на рівень) |
| `*` | ключ від виходу (зараз не використовується) |
| пробіл | порожнеча за межами карти |

## Що де налаштовувати

- **Швидкість, зір, ліхтар, чуття ворогів:** префаби `Prefabs/Skeleton` і `Prefabs/Spirit`, компонент `GuardAI` (lanternRadius, senseRadius, viewDistance, noticeTime...). Складність з меню множить ці числа (`GameSettings`).
- **Скіни:** компонент `GhostSkin` на `Prefabs/Player`. Новий скін: 14 кадрів (`ghost_idle_0..3`, `ghost_move_0..3`, `ghost_caught_0..5`) у новій папці `Sprites/Characters/Ghost/<назва>/` і рядок у `GameBuilder.Skins`.
- **Гучність, ціна в енергії, тривалість приманок:** префаби `Vase` (глечик), `TV` (патефон), `Phone` (дзвін), `Mannequin` (обладунки), компонент `LureObject`.
- **Швидкість привида:** префаб `Player`, `PlayerMovement` (2D) і `FirstPersonMovement` (3D).
- **Наскільки темно:** `Global Light 2D` у сцені рівня, а для 3D ще й `RetroView` на камері (туман, яскравість).
- **Передісторія:** сцена `Intro`, компонент `IntroCutscene` (кадри й тексти).

## Як замінити графіку чи звук

Заміни PNG у `Assets/Sprites/...` або WAV у `Assets/Audio/...` файлом з тією ж назвою. Назви файлів лишилися від першої версії (наприклад, `vase.png` - це глечик, `tv_off.png` - патефон, `phone.png` - дзвін, `mannequin.png` - обладунки, `lamp.png` - смолоскип, `pumpkin.png` - свічки, `carpet.png` - бруківка). Спрайти малюються 32×32, скелет і дух 64×64.

## Як зробити готову гру (.exe)

**Tools > Ghost > Зібрати Windows-версію (.exe)** - збирає всі сцени й кладе гру в `Build/Windows/PryvydPidzemellya.exe` (поруч лежать потрібні папки, роздавати треба всю папку Windows, наприклад архівом на itch.io). Назва гри, іконка (`Sprites/UI/app_icon.png`) і повноекранний режим ставляться самі. Перша збірка може йти кілька хвилин.

## Шрифт

`Assets/Resources/Fonts/PryvydPixel.ttf` - піксельний шрифт з українськими літерами, зроблений з GNU Unifont (SIL OFL 1.1). Найчіткіший при розмірах 16, 32, 48, 64...
