# Після закриття

Стелс-гра про прозорого привида в нічному універмазі. У темряві привида не видно, а світло ліхтарів сторожів і ламп його виказує. Щоб дістатися виходу, привид заманює охорону приманками: розбиває вази, вмикає телевізори, дзвонить на телефон, штовхає манекени.

## Як зібрати гру

1. Відкрий проєкт у Unity і дочекайся, поки скомпілюються скрипти.
2. Меню **Tools > Ghost > Зібрати всю гру**.
3. Відкриється сцена `MainMenu`. Тисни **Play**.

Кнопка створює префаби в `Assets/Prefabs` (лише ті, яких ще немає), сцени `MainMenu` і `Level_01..03` в `Assets/Scenes` і записує їх у Build Profiles. Її можна натискати скільки завгодно: сцени рівнів перебудовуються з текстових карт, а префаби, які ви вже налаштували руками, не чіпаються.

**Tools > Ghost > Перезібрати префаби й гру** створює префаби заново (ручні зміни в них зникнуть).

## Керування

WASD або стрілки: летіти. E: використати приманку. R: почати рівень заново. Esc: у меню.

## Як змінити рівень

Рівні лежать у `Assets/Levels/level_01.txt` і т.д. Відредагуй текст і натисни «Зібрати всю гру». Новий файл `level_04.txt` автоматично стане четвертим рівнем.

```
name: Назва рівня
hint: Підказка, що з'являється на старті
guard: 1 2 3 4      <- маршрут першого сторожа по точках 1, 2, 3, 4 (і по колу)
guard: 5 6          <- другий сторож
map:
########
#P..1..E
########
```

| Символ | Що це |
|---|---|
| `#` | стіна |
| `.` | підлога |
| `P` | старт привида (рівно один) |
| `E` | вихід (ставиться на місце стіни) |
| `1`..`9` | точки маршруту сторожів; сторож з'являється на першій точці свого маршруту |
| `S` / `s` | полиця (два види) |
| `C` | каса |
| `p` | вазон із рослиною |
| `L` | лампа (освітлює коло, у якому привида видно) |
| `V` | ваза (разова приманка) |
| `T` | телевізор (шумить 5 секунд) |
| `H` | телефон (найгучніший) |
| `M` | манекен; `m` поруч показує, куди його штовхнути |
| пробіл | порожнеча за межами карти |

## Що де налаштовувати

- **Швидкість, зір, час упізнавання сторожа:** префаб `Prefabs/Guard`, компонент `GuardAI`.
- **Гучність, ціна в енергії, тривалість приманок:** префаби `Vase`, `TV`, `Phone`, `Mannequin`, компонент `LureObject`.
- **Швидкість привида:** префаб `Player`, `PlayerMovement`. Енергія: `PlayerEnergy`. Прозорість: `GhostVisibility`.
- **Наскільки темно:** об'єкт `Global Light 2D` у сцені рівня (Intensity).
- **Як швидко спадає підозра і скільки триває тривога:** `SuspicionMeter` на об'єкті `GameManager`.
- **Текст меню:** `MainMenu` у сцені `MainMenu` (назва гри, підзаголовок, титри).

## Як замінити графіку чи звук

Просто заміни PNG у `Assets/Sprites/...` або WAV у `Assets/Audio/...` файлом з тією ж назвою. Спрайти малюються 32×32 пікселі, одна клітинка карти = 32 пікселі. Нові картинки в `Assets/Sprites` автоматично отримують правильні налаштування піксель-арту.

## Як працює сторож

Патрулює маршрут → почув приманку в радіусі → іде перевіряти й оглядається → повертається на маршрут. Якщо бачить освітленого привида у своєму конусі, спершу зупиняється зі знаком «?», а якщо привид не встиг сховатися, кричить «!» і женеться. Загубив на 2 секунди: шукає там, де бачив востаннє. Кожна приманка й кожна гонитва піднімають загальну підозру; коли вона доходить до максимуму, вмикається тривога і всі сторожі стають швидшими й пильнішими.
